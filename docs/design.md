# 看台之外 · 球场影像志

首版定位：中文足球场影像与故事展示网站，面向球迷和足球建筑爱好者。用户已选择图片与故事优先。

视觉：暖白纸张底色、海军蓝文字、珊瑚红重点色，编辑式版面。首页用大字标题、安菲尔德全景图建立主题，再进入球场探索。

内容：10 座欧洲著名俱乐部球场，覆盖英格兰、西班牙、德国、意大利、法国。每座球场包含中英文名、俱乐部、城市、启用年份、简短故事、特色与官方来源。翻修中球场和历史照片明确标注。

交互：联赛筛选、中英文搜索、收藏并在本机保存、收藏视图、球场详情对话框、随机发现、故事专题。空结果提供重置操作。全站适配桌面与手机，键盘可操作，尊重减少动画设置。

实现：无构建依赖的 HTML/CSS/JavaScript，球场内容置于独立数据模块，静态资源本地打包。无账户和服务器数据存储。通过 Sites 创建默认私有站点。

验证：脚本语法检查、资源完整性检查、桌面及移动浏览器预览，验证筛选、搜索、收藏持久化和对话框。真实球场图片保留摄影者、许可与来源记录。
