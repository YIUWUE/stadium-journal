# 球场 3D 与纯音频 · 第三版

用户选择：风格化建筑模型；原创足球氛围 BGM。保留已发布的夜场视觉、24 座球场、收藏、推荐与探索护照。

详情页打开即显示交互模型。每座模型有独立建筑参数，包括平面轮廓、看台层数、配色、屋顶形式、外立面和标志性结构。它是建筑特征示意，不宣称测绘精度或最新改建状态。

模型支持鼠标拖拽旋转、右键平移、滚轮缩放；触屏单指旋转、双指缩放与平移。提供放大、缩小、俯瞰与重置视角按钮，以及键盘操作。实景图片仍可切换查看。

Three.js 与 OrbitControls 固定版本并本地打包，不依赖外部 CDN。渲染按需启动，关闭详情即停止；切换球场释放旧几何与材质，复用 WebGL 上下文。弱设备限制像素比；不支持 WebGL 时给出实景替代入口。

移除所有视频、iframe、视频 API 和播放面板。改用本地 Web Audio 原创编曲，不引用球队现有旋律、歌词或录音。24 座球场通过确定性的编曲参数呈现不同音色与节奏，界面明确标注原创氛围音乐。

在点击球场的同一个交互调用中恢复 AudioContext；音乐从零音量渐入至低音量。只保留小静音按钮。静音偏好保存在浏览器。关闭详情淡出并停止，切换时旧声道先淡出，页面隐藏时暂停。若浏览器限制声音，不虚构正在播放状态。

验证：全部模型配置与资源完整性、模型渲染截图、旋转/平移/缩放/重置、触屏尺寸、Web Audio 实际运行状态、渐入曲线、静音与退出清理、零视频 DOM 与旧功能回归。
