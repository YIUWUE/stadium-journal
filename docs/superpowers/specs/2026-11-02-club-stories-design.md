# 球队与主场故事

用户希望选择球队后读到更多球队与球场故事。沿用城市开场、横向选队与既有模型展台，不增加选择层级。

每座主场提供一篇中文故事：主题导语、球队起源、主场来历、历史瞬间三章，四个关键年份。全部 24 座覆盖；圣西罗和马拉卡纳同时讲述两支主队。球队成立、场馆启用、改名、迁入分别说明，比赛注明实际举办地。

模型下方提供「读球队与主场故事」入口；文章采用连续阅读版式，章节目录在同一详情内平滑定位，滚动时显示当前章节。移动端目录横排，时间线移到文章下方。减少动态效果偏好生效。

事实以俱乐部、场馆或赛事组织的一手历史资料为依据，独立中文转述，章节附近显示资料链接，完整目录可展开。不推断球迷性格，不添加未经核实的引语，不把历史照片或模型描述成今日实景。
