# 互动球场展 · 第二版

用户授权：更酷的视觉、更多交互、过渡与特效、扩充球场，以及点击球场后低音量尝试播放对应球队歌曲。音乐播放方式已由用户选择。

方向：夜场看台。墨黑背景、荧光绿强调色、大幅真实影像与编辑式大字，保留“看台之外”的中文品牌。文案让初次接触足球的人也能理解。

内容：扩展至 24 座球场，覆盖欧洲与南美。保留现有收藏数据，增加按氛围、建筑和城市筛选，加入新手友好的观看亮点。

交互：主场偏好测试、封面切换、探索护照（记录在网站内看过的球场，不代表真实到访）、收藏、联赛与主题筛选、详情内上一站/下一站、随机探索。用真实行为更新探索进度，不使用虚构热度。

动效：图片交叉淡化、滚动渐入、卡片轻微倾斜、对话框入场与离场、护照盖章。遵循 prefers-reduced-motion，不使用持续闪烁或强制音效。

音乐：使用公开发布的球队音乐视频嵌入，保留可见播放器和原站链接，不复制录音。默认音量 12%，上限 30%，支持暂停、静音、音量调节和关闭自动播放。自动播放失败、网络超时和禁止嵌入均给出明确状态。缺少已核实播放源的球队显示官方音乐入口，不以其他球队或合成音冒充队歌。关闭详情时停止；切换球场时销毁旧播放器，避免串音。

验证：资源与数据完整性、JavaScript 语法；浏览器检查筛选、偏好测试、护照持久化、收藏兼容、详情切换、键盘关闭、手机宽度与音频失败状态。外部播放器成功与否分别记录，不将播放请求视为实际出声。
