# 看台之外 · 循着颜色，找到主场

第九版将主流程简化为「城市氛围开场 → 一屏球队选择 → 球场模型揭晓」。收录 24 座球场、13 座作者模型及 24 座精细建筑重建。

## 运行与验证

`npm run dev` 启动 http://127.0.0.1:4173/ 。无需安装应用依赖。`npm run check` 检查全部脚本语法、球场模型/音源元数据、球队标识和城市摄影覆盖及来源。浏览器验证使用 Playwright CLI，截图与临时记录放在忽略的 `output/playwright/`。

## 体验

首页先显示马德里城市影像、简短文案和轻微鼠标视差，没有球场模型、自动音乐或地图。点击「开始探索」或向下滚动，进入球队选择。球队标识为本站设计的颜色与字母图形，并非官方队徽。

鼠标移向球队带左右边缘时自动平滑浏览，中心区域休息、移开或打开弹窗即停止；移除点击箭头。触屏继续原生滑动，键盘方向键/Home/End 和鼠标拖动仍可使用。减少动态效果偏好关闭连续鼠标滑动。悬停、键盘聚焦或滑动停留时更新城市背景、球队名称与一句故事。点击球队标识或当前主场入口直接进入 3D 展台。保留联赛、关键词和收藏筛选。取消地球、国家、城市及同城局部图的多级导航。

触屏使用原生横向滚动，鼠标拖动与点击区分，拖拽后不误开模型。方向键、Home/End 可浏览球队，Enter 进入。减少动态效果偏好关闭视差和过渡。每次仅加载已选城市影像；3D 依赖和模型在进入展台时加载。

## 模型、声音及个人记录

原有精细模型、真实历史影像、来源和署名保留。作者模型使用原发布方 Sketchfab Viewer API，显式请求 HD 纹理和锐化；不提取或重新分发受限模型文件。24 座本地精细建筑重建不含周边城市建筑，属于建筑解释，并非测绘文件。

点击球场后真实主队歌曲/助威录音自动尝试播放，约 3.5 秒渐入至 10% 音量，保留小静音按钮。无视频或原创替代曲。关闭展台后停止，页面隐藏时暂停。音源或自动播放失败时显示真实状态。

收藏、探索印章、静音偏好沿用既有浏览器存储键；探索护照从顶部导航打开，主队匹配问答从开场或页尾进入。

## 主要文件

- `dist/club-gallery.js`、`club-experience.css`：城市背景、原创球队标识、拖动/聚焦/直接进入及过渡。
- `dist/assets/cities/`、`city-credits.json`：真实城市摄影和逐项许可、作者及来源。
- `dist/detailed-models.js`、`detailed-viewer.js`：作者模型及 HD 纹理请求。
- `dist/model-profiles.js`、`stadium-viewer.js`：24 座精细建筑重建。
- `dist/audio-tracks.js`、`ambient.js`：主队音源及音频生命周期。
- `dist/app.js`：筛选、展台、收藏、护照及来源弹窗。

复用 `.openai/hosting.json` 的项目身份和原有私有访问范围。

## 用真实比赛数据寻找主队

首页和页尾可进入四题观赛偏好问答。根据进球密度、国内赛事赢球频率、球队进球/零封比例以及主客场积分率匹配三家候选俱乐部。每题等权；无偏好不计分；全部无偏好时明确给出三种风格的探索起点，不冒充个性化推荐。不显示未经验证的命中率或人格标签。

数据由 47 份 Football-Data.co.uk 公开 CSV 汇总，共处理 19,839 场窗口内赛事，其中 4,220 场独立比赛涉及本库的 24 家候选俱乐部（4,473 次俱乐部视角记录）。欧洲取 2020/21—2024/25；阿根廷与巴西按 2021—2025 自然年。主队字典及共享球场的主队选择、赛制差异、来源哈希和计算方式详见 `docs/data-methodology.md`。问答采用公开统计与可解释的手工匹配规则，未进行球迷偏好训练或准确率验证，不是世界实力排名。答案仅在本页计算。

- `scripts/build-club-data.py`：可复现数据构建；`--offline` 使用忽略的 `research/football-data/` 缓存。
- `dist/assets/club-match-data.json`：仅赛果聚合与来源审计元数据，不含赔率。
- `dist/team-match.js`、`quiz.js`：偏好维度、分位距离排名、证据解释和问答界面。
- `scripts/check-team-match.mjs`：81 种答案路径、指标与原始计数一致性、稳定排名及中立答案处理。

来源限定私人个人用途，未提供开放数据许可；本站保留所有者私有访问。公开、商业化、重新分发或训练前须重新核实来源授权。当前功能仅做透明算术匹配，不进行模型训练。
