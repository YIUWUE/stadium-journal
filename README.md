# 看台之外 · 球场影像志

介绍欧洲知名足球俱乐部主场的中文展示网站。首版包含 10 座球场、联赛筛选、中英文搜索、浏览器本机收藏、详情弹窗、三个故事专题和随机探索。

## 本地预览

在本目录运行 `npm run dev`，浏览器打开 `http://127.0.0.1:4173`。无需安装依赖。`npm run check` 检查脚本语法。

## 内容维护

- `dist/data.js`：球场与故事数据。
- `dist/styles.css`：响应式样式。
- `dist/app.js`：筛选、搜索、收藏与弹窗逻辑。
- `dist/assets/credits.json`：摄影者、图片来源和许可记录。

图片为历史实景，详情页说明时间背景。收藏保存在当前浏览器，不跨设备同步。字体打包在 assets/fonts 中。此项目不是俱乐部官方网站。

Sites 身份配置保存在 `.openai/hosting.json`，更新时须复用该项目 ID。
