# 看台之外 · 互动球场展

第四版收录 24 座球场、17 座原作者在线精细模型、24 座可离线运行的建筑重建，以及 24 组对应主队的歌曲或助威纯音频。

## 运行

`npm run dev` 后打开 http://127.0.0.1:4173 。无需安装依赖。`npm run check` 检查语法、资源和来源元数据。

## 交互封面

双列大幅摄影封面，鼠标位置驱动光斑、轻微倾斜和影像视差。悬停或键盘聚焦展开简介与入口。触屏直接显示入口，减少动态效果偏好关闭移动效果。整张封面可打开球场，收藏按钮独立操作。

## 球场模型

有精细资产的球场默认加载原作者的 Sketchfab 交互模型，保留作者与来源。使用官方 Viewer API 1.12.1，不抓取或重新分发模型文件。加载失败自动切换本站建筑重建，也可随时手动切换。模型可能记录历史阶段，不保证反映最新改建。

本地建筑重建新增独立座椅与靠背、分区过道、栏杆、通道口、屋顶桁架、玻璃与立面分层、球网、草皮纹理、地面广场和方向阴影。是建筑结构示意，并非测绘模型。支持左键旋转、右键平移、滚轮缩放；手机单指旋转、双指平移或缩放。本地工具栏提供内场、外观、俯瞰等视角。画布聚焦后方向键旋转、Shift + 方向键平移、加减号缩放、Home 重置。

Three.js 0.187.0 与 OrbitControls 本地打包并保留 MIT LICENSE。座椅和屋架采用实例化渲染；切换时释放资源，关闭详情停止渲染。同一时刻只显示一个模型。

## 主队纯音频

`dist/audio-tracks.js` 保存实际音源、曲名、来源页和提供者。巴萨使用俱乐部官方下载页发布的助威音频，其余使用公开球迷歌曲档案或河床球迷录音。共享球场当前选择 AC 米兰与弗拉门戈的声音，曲名明确标注球队。不将球迷档案称为官方录音，不重新分发音频文件。

点击球场时通过原始纯音频地址自动尝试播放，约 3.5 秒渐入至 10% 音量，保留小静音按钮。没有视频、隐藏视频播放器或原创替代旋律。浏览器限制自动播放或音源连接失败时显示真实状态。关闭详情淡出并停止；切换球场清理旧音源；页面隐藏暂停。静音偏好、收藏、护照保存于当前浏览器。

## 主要文件

- `dist/catalog.js`、`dist/data.js`、`dist/extra-data.js`：24 座球场的内容。
- `dist/covers.css`：交互封面及详情补充样式。
- `dist/detailed-models.js`、`dist/detailed-viewer.js`：原作者模型元数据与在线展示生命周期。
- `dist/model-profiles.js`、`dist/stadium-viewer.js`：本地建筑结构与交互。
- `dist/audio-tracks.js`、`dist/ambient.js`：真实主队音源与低音量播放生命周期。
- `dist/app.js`：探索、详情、收藏、护照与模式切换。
- `dist/assets/credits.json`：照片摄影者与许可。

沿用 `.openai/hosting.json` 的 Sites 项目身份与原有私有访问设置。
