# 看台之外 · 互动球场展

深色夜场风格的中文足球场体验网站。现有 24 座球场、11 个足球国度，以及 24 组对应球队歌曲或球迷助威视频。

## 本地运行

运行 `npm run dev`，打开 http://127.0.0.1:4173 。无安装或构建依赖。

## 体验

- 按联赛、地区、氛围、建筑、历史、城市筛选，并支持中英文搜索。
- 三道偏好题推荐主场；探索护照记录在站内打开过的球场。
- 收藏沿用第一版的本机存储键，已有收藏保持兼容。
- 三个封面切换、卡片轻微倾斜、滚动渐入、详情进出场及盖章动效；遵循减少动态效果偏好。
- 点击球场后尝试播放对应球队音乐或助威录像。初始音量 12%，可调 0–30%，支持暂停、静音和关闭自动音乐。
- 音乐通过可见的 YouTube 播放器播放，保留原站链接，不复制录音。部分为官方发布，部分为艺人演绎或球迷录像，均在界面标注。地区、网络或发布方设置可能限制播放；界面提供重试与原站入口。

## 文件

- `dist/catalog.js`：合并与标注球场；`dist/data.js` 与 `dist/extra-data.js` 保存资料。
- `dist/app.js`：探索、详情、收藏、护照和视觉交互。
- `dist/quiz.js`：偏好测试。
- `dist/music.js`：球队音源及播放器生命周期、音量和失败状态。
- `dist/night.css`：新版响应式设计与动效；`dist/styles.css` 为本地字体声明。
- `dist/assets/credits.json`：摄影者、许可、原始文件记录。

球场照片为历史实景，详情内标明时间背景。收藏、护照和自动音乐偏好保存在当前浏览器，不跨设备同步。没有实时票务、容量或赛程数据。

复用 `.openai/hosting.json` 中现有 Sites 项目 ID 发布，保持原有私有访问设置。
