# 看台之外 · 互动球场展

第三版包含 24 座足球场的交互式风格化建筑模型、纯音频原创氛围音乐，以及夜场视觉、收藏、偏好测试与探索护照。

## 运行

`npm run dev` 后打开 http://127.0.0.1:4173 。无需安装依赖。`npm run check` 检查语法与数据、资源完整性。

## 3D 操作

点击球场默认进入 3D。鼠标左键拖拽旋转，右键或 Shift 拖拽平移，滚轮缩放；触屏单指旋转，双指缩放与平移。工具栏提供放大、缩小、俯瞰、缓缓环绕和重置。

聚焦画布后，方向键旋转、Shift + 方向键平移，加减号缩放，Home 重置。支持减少动态效果偏好。

模型表达建筑特征，为风格化示意，并非测绘还原或最新改建成果；可切换历史实景图片。

Three.js 0.187.0 与 OrbitControls 本地打包于 `dist/vendor/three`，保留 MIT LICENSE。WebGL 上下文复用，切换时释放旧资源；关闭详情停止渲染。不支持 WebGL 时提供实景入口。

## 原创纯音频

采用用户选择的原创足球氛围 BGM。24 组独立参数，包含原创器乐和声、旋律与轻打击；未引用球队现有旋律、歌词或录音。

点击球场时在同一交互中恢复 Web Audio，约 3.6 秒渐入至低音量。只保留小型静音按钮，没有视频、iframe、播放器面板、开始播放按钮或外部音源请求。关闭详情淡出停止，切换场馆清理旧声部，页面隐藏时暂停。浏览器的自动播放政策仍可能影响声音。

静音偏好、收藏与探索护照存于当前浏览器。收藏继续复用第一版键，不跨设备同步。

## 内容与源码

- `dist/catalog.js`、`dist/data.js`、`dist/extra-data.js`：球场内容。
- `dist/model-profiles.js`：24 座球场的建筑特征与几何配置。
- `dist/stadium-viewer.js`：Three.js 模型与交互。
- `dist/ambient.js`：原创音乐编曲与音频生命周期。
- `dist/app.js`：探索、详情、收藏和护照。
- `dist/quiz.js`：三步主场偏好测试。
- `dist/assets/credits.json`：历史照片的摄影者与许可记录。

复用 `.openai/hosting.json` 中的 Sites 身份与原有私有访问设置。
