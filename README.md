# 看台之外 · 主场星图

第五版以可旋转的地球星图取代选场卡片。收录 24 座球场、13 座经过筛选的作者模型，以及 24 座独立的精细建筑重建。

## 运行

`npm run dev` 后打开 http://127.0.0.1:4173 。无需安装依赖。`npm run check` 检查语法、资源、音源元数据和全部星图坐标。

## 星图探索

拖拽地球旋转，滚轮或工具栏缩放；点击坐标进入球场展台。同城球队聚合为城市坐标，展开后选择具体主场。保留关键词、联赛、主题及收藏筛选和可使用键盘的坐标索引。点击主场时，地球镜头推进并切入模型展台；关闭后恢复之前的星图视角。支持触屏及减少动态效果偏好。

地形来自 Natural Earth 公共领域地图数据；方位坐标用于探索示意，不用于导航。数据与本地 Three.js 打包，浏览器不必调用地图服务。

## 独立球场模型

伯纳乌、诺坎普、安联、安菲尔德和马拉卡纳更换为以球场本体为主体的作者素材。诺坎普明确标注为扩建方案模型。撤下带有大面积城市或独立附属场地的巴黎、纪念碑、大都会和老特拉福德旧扫描，默认使用精细重建。保留用户认可的伊蒂哈德等球场本体展示。

作者模型使用原发布方 Sketchfab Viewer API 1.12.1，显式请求 HD 贴图并启用锐化。保留署名，不提取或重新分发模型文件。源文件的几何和贴图仍决定可见细节，不能将锐化说成恢复了原始素材中不存在的细节。

本地 24 座精细建筑重建均不含周边建筑、街道、广场或树木。补强尤文、斯坦福桥、光明、克鲁伊夫、德奎普、凯尔特人公园和马拉多纳七座的独立结构。模型拥有成型座椅及靠背、结构屋架、立面分层、入口、球网、2K 草皮和招牌、环境反射与方向阴影，使用较高渲染分辨率和更近的取景。是原创建筑重建，不是测绘文件，也不保证代表最新改建状态。

本地模型支持拖拽旋转、右键或双指平移、滚轮或双指缩放，另有内场、外观、俯瞰及重置视角。画布聚焦后方向键旋转，Shift+方向键平移，加减号缩放。切换或关闭模型释放上一组资源；展台打开时暂停星图。

## 主队声音

24 组真实主队歌曲/助威录音沿用上一版，巴萨为官方发布的音源，其余为公开球迷歌曲档案或球迷录音。音频仍留在原发布方，点击球场时自动尝试播放，约 3.5 秒渐入至 10% 音量，只保留小静音按钮。无视频、隐藏视频播放器或原创替代曲。音源失败或自动播放受限时显示真实状态。关闭后淡出停止，页面隐藏时暂停。

收藏、探索印章与静音偏好保存在当前浏览器，继续复用既有存储键。

## 文件

- `dist/stadium-atlas.js`、`dist/atlas.css`：星图、城市聚合、坐标索引及飞入过渡。
- `dist/assets/earth-land.json`：Natural Earth 轮廓数据。
- `dist/detailed-models.js`、`dist/detailed-viewer.js`：作者模型与高清纹理请求。
- `dist/model-profiles.js`、`dist/stadium-viewer.js`：24 座精细建筑重建。
- `dist/audio-tracks.js`、`dist/ambient.js`：音源和音频生命周期。
- `dist/app.js`：筛选、展台、收藏、护照和音量。

复用 `.openai/hosting.json` 的项目身份与原有私有访问范围。
